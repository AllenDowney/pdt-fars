# Working in pdt-fars

FARS metadata built to the PublicDataToolkit standard (`../PublicDataToolkit/STANDARD.md`). PublicDataToolkit Task 13.

- `metadata/` and `build/report.md` are generated by `build/build_slice.py`; edit the build or `build/slice.yaml`.
- `data/` is gitignored. `data/raw/` holds the downloads Allen made from nhtsa.gov (which blocks scripts and headless browsers); `data/interim/manual.txt` is the manual converted with `pdftotext -layout`.
- The manual's code tables are matrices of year ranges. A table that continues onto the next page repeats its header; labels wrap at the label column; discontinued elements can share a SAS name with current ones. The parser handles all three.
- Terms are in `dataset.yaml` (everything ship, reviewed by Allen, 2026-11-19).
