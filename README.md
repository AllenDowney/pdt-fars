# pdt-fars

Metadata for the [Fatality Analysis Reporting System](https://www.nhtsa.gov/research-data/fatality-analysis-reporting-system-fars) (FARS), built to the [PublicDataToolkit](https://github.com/AllenDowney/PublicDataToolkit) standard.

**Status:** preliminary. A 32-variable slice of the 2024 national files, in three tables: crashes (14 variables), vehicles (8) and people (10).

## What the dataset is

FARS is NHTSA's census of fatal motor vehicle crashes in the US since 1975, coded from police reports and other records. Each year's data has about 30 files, linked by crash (`ST_CASE`), vehicle (`VEH_NO`) and person (`PER_NO`).

## Terms of use

FARS is a US government work, distributed by NHTSA with no license or restriction. The terms as reviewed are in [`dataset.yaml`](dataset.yaml).

## How to get the data

From NHTSA's FARS data downloads, in a browser (the site blocks scripts). [`sources.yaml`](sources.yaml) lists each file, where it goes in `data/raw/`, how to get it, and its checksum. To check what you have:

```bash
make download
```

That never fetches anything. It reports each file as present, missing or changed, and prints the steps for any that are missing.

## The metadata

- `metadata/releases/<release>/<table>/variables.jsonl`, for releases `2024` and `2017` and the tables `accident`, `vehicle`, `person` and `parkwork`. Each record has the element's title, its definition and additional information (in `notes`), and that year's codes, with labels from that year's data file and "Not Reported" and "Unknown" typed by rule. It also records where each fact came from.
- `metadata/histories.jsonl`: each element's codes by year range since 1975, as the manual's code tables give them.
- `metadata/links.jsonl`: how each variable changed from 2017 to 2024, generated by rule from the histories.

## How to cite

National Center for Statistics and Analysis. (2026, April). Fatality Analysis Reporting System analytical user's manual, 1975-2024 (Report No. DOT HS 813 794). National Highway Traffic Safety Administration. https://doi.org/10.21949/dz60-ft73

## How to rebuild

With the sources in `data/raw/`, the manual converted to `data/interim/manual.txt`, and a PublicDataToolkit checkout next to this repo:

```bash
make download   # check the sources
make build      # the records, histories and links
make data       # the data in the common format, data/processed/
make check
```

`scripts/extract.py` writes an extract from the common-format files (`make data` first), for example:

```bash
python scripts/extract.py --release 2024 --table person --vars ST_CASE,AGE,SEX,INJ_SEV --codes \
    --out persons.csv
```

`python scripts/extract.py --help` lists the releases and tables and the options.
